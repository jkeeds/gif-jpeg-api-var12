## Что необходимо проверить у себя в Codespaces

Здесь нет установленных пакетов Bottle и Hypothesis, а установка из сети
недоступна. Поэтому реальные HTTP-запросы и тесты Hypothesis **ещё не
проверены**, утверждать об отсутствии любых ошибок нельзя.

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m coverage erase
python -m coverage run --branch --source=src -m unittest tests.test_mbt
python -m coverage report -m
```

Оценка покрытия относится к ветвям и проверке обработчиков — она не
подменяется двумя юнит-тестами конвертера. При наличии интернета также
можно установить и запустить `ruff check .` и `radon cc -s src`.

**Важно:** исходная Git-история создана с временным именем автора `Student`.
Перед публикацией следует указать свои имя и e-mail и при необходимости
исправить автора прошлых коммитов.
